# EC11 + TIM3 编码器验证

- 日期：2026-11-02
- 编码器：EC11_V1.3（303ENC00ER2），机械触点，20 PPR，C 脚为按键
- 接线：VCC→3.3V，GND→GND，A→PA6，B→PA7
- 模式：TIM3 编码器接口，`TIM_EncoderMode_TI12`（4 倍频），`TIM_ICFilter = 0xF`

## 计数

| 项 | 实测 |
|---|---|
| 一圈计数（串口 enc 差值） | **80** |
| A 相一圈上升沿 | **20** |
| A 相高电平（万用表） | **3.24 V** |
| 波形 | 规则方波，无明显毛刺 |

> 波形截图 `ec11-waveform.png` 覆盖约两圈；单圈 20 个上升沿已由计数确认。

## 菜单

- 一档 = **4 计数**
- 初版问题：慢转一档，屏幕无反应
- 根因：`Encoder_Get()` 每次清零，零头被丢弃
- 修复：`static int16_t encAccum` 累加，攒够 ±4 再触发
- 结果：一档翻一页，菜单翻页正常（用户确认）
