# W2.5 第 1 步：PWM 开环驱动电机

- 日期：2026-10-29
- 供电方案：B（USB-TTL 5V → VM）
- 仪器：NanoDLA + PulseView 0.5.0-git（PWM 协议解码器）
- 代码：`Hardware/PWM.c`、`Hardware/Motor.c`；`main.c` 中 `Motor_Init()` + `Motor_SetSpeed(50)`
- 接线：PWMA→PA8，AIN1→PA4，AIN2→PA5，STBY→3.3V，VCC→3.3V，VM→USB-TTL 5V，AO1/AO2→电机

## 电机实测（空载）

| 设定 | 现象 |
|---|---|

|---|---|

| 跌落 | 0.5 V（约 10%） |
| 复位 | 无 |
| OLED | 正常，无花屏/黑屏 |

| Keil | 未掉线 |
| USB 电涌 | 无 |

## 问题记录

1. **`if / if-else` 分支配对错误**：`Motor_SetSpeed(20)` 后 `CCR1` 被第二个 `if` 的 `else` 覆盖成 0。
   修复：第二个 `if` 改成 `else if`。详见开发日志「坑14」。
2. **电机接到 VCC/GND**：0% 也持续转；电机绕过了 TB6612。改接 AO1/AO2 后正常。详见开发日志「坑15」。
3. **观测点选早了**：第一次在 `Motor_Init()` 之前看寄存器，全是复位值 0。详见开发日志「坑16」。

## 结论

通过。空载验证可跑；供电余量偏薄，带载/堵转前需换独立电源（4 节 AA 电池盒或手机充电头）。
