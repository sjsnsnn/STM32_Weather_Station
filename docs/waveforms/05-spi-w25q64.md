# SPI W25Q64 波形实测

> 日期：2026-11-23
> 目的：用 NanoDLA + PulseView 验证 SPI2 与 W25Q64 的硬件时序，确认 CS/SCK/MOSI/MISO、命令字节和页写入数据。

## 一、接线

| NanoDLA | STM32 / W25Q64 |
|---|---|
| CH0 | PB12 / CS |
| CH1 | PB13 / SCK |
| CH2 | PB15 / MOSI（DI） |
| CH3 | PB14 / MISO（DO） |
| GND | GND（必须共地） |

## 二、采集参数

| 项 | 值 |
|---|---|
| 仪器 | NanoDLA（8 通道）+ PulseView |
| 采样率 | 24MHz |
| 采样深度 | 5M samples（约 208ms） |
| 触发 | D0（CS）下降沿，Single |
| 测试代码 | 临时启用 `W25Q64_Test()`，复位后自动执行 ID / 擦除 / 页写入 / 回读 |

## 三、SPI 解码器设置

| 设置 | 值 |
|---|---|
| CLK | D1 |
| MOSI | D2 |
| MISO | D3 |
| CS# | D0 |
| CS# polarity | active-low |
| Clock polarity (CPOL) | 0 |
| Clock phase (CPHA) | 0 |
| Bit order | MSB first |
| Word size | 8 |

## 四、实测结果

### 1. JEDEC ID

```text
MOSI: 9F FF FF FF
MISO: FF EF 40 17
```

- 第一个 MISO `FF` 是发命令期间的 dummy；
- 真正的 ID 是 **`EF 40 17` = W25Q64**；
- 证明 CS、SCK、MOSI、MISO、CPOL/CPHA 全部正确。

### 2. 状态寄存器与忙等待

```text
MOSI: 05 FF
MISO: 00 03
```

- `0x05` = Read Status Register 1；
- 第一个 MISO `00` 是命令期间的 dummy；
- 第二个字节 `0x03` = **WIP=1、WEL=1**，表示芯片正在擦除/写入；
- 后续读到 `0x00` 表示空闲；
- 对应代码 `W25Q64_WaitBusy()` 的轮询。

### 3. 页写入

```text
MOSI: 06
MOSI: 02 00 00 00 57 32 35 51 36 34 20 54 45 53 54 20 31 32 33 34
```

- `0x06` = Write Enable；
- `0x02` = Page Program；
- 24 位地址 `00 00 00`；
- 16 字节数据：

```text
57 32 35 51 36 34 20 54 45 53 54 20 31 32 33 34
 W  2  5  Q  6  4     T  E  S  T     1  2  3  4
```

即 `"W25Q64 TEST 1234"`。

### 4. SCK 频率

- 代码配置：SPI2 在 APB1，`SPI_BaudRatePrescaler_8`，36MHz / 8 = **4.5MHz**；
- PulseView 光标读数显示约 `208.333ns / 4.800MHz`；
- 24MHz 采样下，4.5MHz 周期 `222.2ns` 约等于 5.33 个采样点；光标吸附到采样点后会显示 5 个点（208.3ns），因此读数略高；
- 按配置和字节时序判断，实际 SCK 为 **4.5MHz**，与代码一致。

### 5. 未截到的部分

本次截图没有包含 `0x03` Read Data 那一帧；  
W25Q64 的擦除/页写入/回读功能已经在串口测试中验证：

```text
W25Q64 ID: EF4017
after erase: FF FF ...
read back:   57 32 35 51 ...
W25Q64 test: PASS
```

## 六、结论

- SPI2 的 CS/SCK/MOSI/MISO 接线和 Mode 0 配置正确；
- JEDEC ID、状态寄存器、Write Enable、Page Program 命令均被解码验证；
- 页写入数据与预期字符串一致；
- 状态轮询 `0x03 → 0x00` 验证了 WIP 忙等待逻辑；
- 读回数据已在串口测试中验证 PASS。

## 七、复现步骤

4. 点 Run，复位板子；
5. 添加 SPI 解码器，按上面的设置配置；
6. 抓完后放大到 µs 级，查看 `9F / 05 / 02` 等命令；
7. 抓完把 `W25Q64_Test();` 重新注释掉。
